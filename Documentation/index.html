Trust & Transparency

FinNews AI simplifies financial information for educational and informational purposes. Summaries are AI-generated and should be checked against the original source.

  • Source attribution. Every story names its publisher.
  • Original article link. One click back to the full report.
  • AI-generated label and timestamp on every summary.
  • Not financial advice. We explain the news; we don't tell you what to buy or sell.

About FinNews AI

FinNews AI is built to make financial reporting readable. Headlines are retrieved through NewsAPI and passed to a FastAPI backend, which asks Groq's Llama 3.3 70B model to rewrite each story in plain language. The interface you're using is a lightweight HTML, CSS and JavaScript frontend, so it stays fast on any device.

It was designed as an educational tool: a way to learn how to read the news, not a replacement for it.
